# GeForce RTX 40 算力解锁（Windows）

[English](README.md)

一个带图形界面和开关的 Windows 一键安装器。每次开机时，在 Windows 加载 NVIDIA 驱动**之前**，它会把 GeForce RTX 40 系显卡上被限速的 **FP32 累加张量核心**打开到满速。

> **实验性软件，只实测过 RTX 4090。** 其他 RTX 40 系显卡也支持，但没有测过（见[支持的显卡](#支持的显卡)）。它会修改固件启动顺序，并在每次开机时对显卡写寄存器。请先读[风险](#风险)，使用风险自负。

## 能得到什么

实测的一块卡的矩阵乘吞吐（**RTX 4090** 24 GB，功耗上限 450 W，PyTorch，单次测量），其他显卡没有测过：

| 测试 | 未解锁（TFLOPS） | 解锁后 | 变化 |
|---|---|---|---|
| TF32 4096³ | 83.7 | ≈130 | **+55%**（每 GHz 约 2 倍） |
| FP16（FP32 累加）4096³ | 159.3 | ≈214 | **+35%** |
| FP16（FP32 累加）8192³ | 152.9 | ≈168 | +10% |
| BF16（FP32 累加）8192³ | 156.5 | ≈178 | +14% |
| FP16（FP16 累加）、FP32 CUDA 核心 | — | — | 不变 |

- 解锁前后的数值结果逐位相同。
- 显卡一直顶在功耗上限，频率会下降，所以达不到理论上的 2 倍。
- 游戏、DLSS、光追、INT8、大模型逐词生成不受益。真实应用（训练、ComfyUI、LLM 预填充）没有实测。

## 工作原理

1. **安装**：在内部硬盘划一个 300 MiB、没有盘符的隐藏 FAT32 分区（也可以用你指定的 FAT32 U 盘），放进一个 UEFI 小程序，并在固件启动顺序里加一项 `GPU Unlock (auto)`，排在 Windows 前面。
2. **固件文件**：约 330 MB 的 NVIDIA 固件输入**在你自己的电脑上下载并提取**，每个文件都和固定的 SHA-256 核对。本仓库不包含任何 NVIDIA 固件。
3. **每次开机**：小程序先确认是预期的那张卡、处于冷态，然后让显卡里签过名的固件应用设置，复位显卡，把显示交还给固件，再启动 Windows。屏幕会短暂黑一下。如果检查在释放显卡的显示驱动**之前**没通过，就不写显卡，Windows 照常启动；如果在那**之后**没通过，程序会停住并要求你断电（见[风险](#风险)）。
4. **第一次开机**：程序会先只读地记下这张卡的身份（保存为 `PROFILE.TXT`）。实测过的那张卡随后在同一次开机里解锁；其他显卡走[支持的显卡](#支持的显卡)里的谨慎流程。
5. **断电即失效**：设置在断电或重启后会丢失，所以每次开机都要重新应用。开关决定的是**下次开机**解不解锁，因为解锁必须在 NVIDIA 驱动加载之前完成。

## 支持的显卡

面向 **GeForce RTX 40 系**显卡：RTX 4090、4080、4080 SUPER、4070 Ti SUPER、4070 Ti、4070 SUPER、4070（标准显存容量，每台电脑一张）。**只实测过 RTX 4090。**

RTX 4070 Ti SUPER 有两种芯片：常见的 AD103 版（PCI ID `10DE:2705`）和后来出现的 AD102 版（`10DE:2689`，4090 芯片的削减版）。两种都支持。AD102 版是根据用户反馈、公开的 PCI ID 列表和媒体报道加进来的，本项目从没在这种卡上运行过。

除 RTX 4090 以外的显卡，程序会更谨慎（每一步都能在窗口里撤销）：

1. **只读。** 安装后第一次开机只读取显卡信息并保存，不向显卡写任何内容。
2. **试解锁一次。** 你点"试解锁一次"，下一次开机才尝试解锁一次。许可在**尝试之前**就被用掉，所以即使屏幕一直黑屏，也不会重复。
3. **成功之后才能自动。** 只有在你这台电脑上验证过一次试解锁成功，才会出现"开启自动解锁"。在那之前，开关只是让开机程序保持开启（读取显卡并等待）；你随时可以把它关掉，同时会取消还没执行的试解锁。

不支持：RTX 4090 D、48 GB 改版卡、笔记本显卡、RTX 4060 系列、30 系和 50 系、一台电脑里有多张受支持的显卡。安装器会拒绝这些显卡；如果检测到其他显示适配器只会警告（开机程序自己会在屏幕不在受支持的显卡上时拒绝运行）。

如果你试了其他显卡，无论成败，请[提一个 issue](../../issues/new/choose) 告诉我们结果。

## 适用条件

安装器的"检查系统"会逐项检查，任何一项不满足都会拒绝安装。

| 项 | 要求 |
|---|---|
| 显卡 | 恰好一张受支持的显卡（见上），显存为标准容量（4090 为 24 GB，4080 系列和 4070 Ti SUPER 为 16 GB，4070 Ti、4070 SUPER、4070 为 12 GB） |
| 系统 | Windows 10 / 11，64 位 |
| 启动方式 | UEFI（不是 Legacy/CSM） |
| Secure Boot | **必须关闭**（开机程序没有签名） |
| BitLocker / 设备加密 | **必须关闭**（改启动路径会触发恢复密钥） |
| 显示器 | 只接在这张受支持的显卡上 |
| 空间 | GPT 磁盘上一个能缩小 304 MiB 的 NTFS 卷，或一个有 150 MB 空闲的 FAT32 U 盘；下载另需约 400 MB（检查要求缓存所在的盘至少有 1 GB 空闲） |

**不支持**：48 GB 魔改卡、4090 D、笔记本显卡、多显卡、Secure Boot 开启。

## 已验证与未验证

| 测试机上已验证 | 未验证 |
|---|---|
| Windows 11 专业版 24H2（26100），驱动 610.88 | Windows 10、家庭版、Server 版 |
| 试解锁流程（只读、等待、试解锁一次、确认），通过 `trial_required=1` 在 4090 上强制走了一遍 | **4090 以外的所有显卡。** AD103、AD104 的芯片表、显存和芯片编号检查是按上游文档写的，AD102 版 4070 Ti SUPER 的条目来自公开的 PCI ID 列表，这些都从没在对应的卡上运行过 |
| 华硕 ROG STRIX Z790-H（BIOS 3107）、i7-14700KF、华硕 RTX 4090 | 其他主板和其他品牌的 4090；有些主板固件不认、或会重置 Windows 里改的启动顺序 |
| 安装、卸载（被缩小的卷恢复到精确原大小）、开关开/关、重新登记 | U 盘模式、安装失败后的回滚 |
| 首次开机登记并解锁、冷启动和重启后自动解锁，成功解锁十余次 | 睡眠（S3）唤醒后（预计会失效）、开启快速启动时、Windows 或 BIOS 更新之后 |
| 用预先放好的缓存和本机的 TLS 1.3 测试服务器核对下载、大小和哈希 | 全新电脑上真正联网下载（archive.cachyos.org 需要 TLS 1.3，Windows 10 可能不支持，这时请手动把文件放进缓存） |
| 100% 缩放，以及模拟 125%/150% 缩放下的界面 | 用户名或路径里有中文等非 ASCII 字符 |

**非常欢迎反馈其他机器的结果。** 请提 issue，附上主板、BIOS 版本、显卡品牌、Windows 版本和开机日志（窗口里的"开机日志"按钮，`FINAL` 行最重要）。

## 安装

1. 在 BIOS 里**关闭 Secure Boot**；在 Windows 里**关闭 BitLocker / 设备加密**。重要数据先备份。
2. 下载发布包（或克隆本仓库），打开 `installer\`，双击 **`GPU-Unlock-Installer.cmd`**，在弹出的管理员提示里选"是"。
3. 点 **"检查系统"**，所有项都要显示"通过"；"注意"只是提醒（实验性显卡一定会有一条）。
4. 点 **"安装…"**，选内部硬盘小分区（推荐）或 U 盘，勾选风险确认（实验性显卡还要勾选额外的一项），点 **"开始安装"**。
5. 提示重启时选"是"。实验性显卡要点"试解锁一次"后再重启一次；试解锁成功后点"开启自动解锁"。

界面是纯中文或纯英文，在右上角 **中文 / English** 切换。

命令行（在 `installer\` 里打开管理员 PowerShell）：

```powershell
powershell -ExecutionPolicy Bypass -File core.ps1 check
powershell -ExecutionPolicy Bypass -File core.ps1 install -Mode partition -TargetVolume D -DryRun
powershell -ExecutionPolicy Bypass -File core.ps1 trial        # 实验性显卡: 开启一次试解锁
powershell -ExecutionPolicy Bypass -File core.ps1 enable | disable | status | logs | reenroll | uninstall
powershell -ExecutionPolicy Bypass -File core.ps1 install -AcceptExperimental   # 实验性显卡需要加这个参数
```

`-DryRun` 只打印计划，不做任何改动；`-Lang en|zh` 指定输出语言。

## 日常使用

- **开关**："开机自动解锁"开关从下次开机起生效。
- **看状态**：大卡片显示**本次开机**是否已解锁。每次重启都会清除解锁；开关开着时，下次开机会重新解锁。
- **某次不解锁**：开机按主板的启动菜单键（华硕一般是 F8，其他常见 F11/F12），选 Windows Boot Manager。
- **试解锁一次**（仅实验性显卡）：为下一次开机开启一次试解锁。试解锁成功后，这个按钮会变成"开启自动解锁"。
- **重新登记显卡**：换显卡、升级 BIOS 或改动主板设置之后使用，同时会重置试解锁状态。
- **卸载**：删除启动项和小分区，并把空间还给原来的卷。

想自己确认速度，可以运行 `python tools/bench_gemm.py 名字`（需要装 CUDA 版 PyTorch），对比一次未解锁开机和一次解锁开机的结果。TF32 的差别最明显。

完整说明书见 [docs/MANUAL-zh.md](docs/MANUAL-zh.md)，包括排障、文件位置和用 `bcdedit` 手动停用的方法。

## 风险

- **可能黑屏**：每次开机都会对显卡写寄存器，没有人在旁边看着。事务中途失败时，程序会停住并要求断电，开机会卡在黑屏。这时长按电源键关机，再开机从启动菜单进 Windows Boot Manager，然后在窗口里把开关关掉。实验性显卡在那一次试解锁里也可能这样；试解锁的许可已经用掉，不会重复。
- **其他显卡没有测过**：除 RTX 4090 外，所有卡的设置都来自上游文档，不是本项目测出来的。参数不对时，程序应在写入之前停下（显卡必须和记录的芯片编号、显存大小和冷态寄存器一致），但这一点没有在那些卡上跑过。
- **快速启动**：开启时，"关机"会恢复上次保存的 Windows 会话而不是全新启动，这一点没有测试过，也可能和开机程序修改的文件冲突。"检查系统"会在它开启时警告；请关闭它，或者一律用"重启"。
- **会改动硬盘**：分区模式会缩小你的一个卷，请先备份。
- **没有签名**：脚本和 EFI 程序都没有签名，杀毒软件或 SmartScreen 可能报警。你可以自己从源码构建 EFI 并比对哈希，见 [efi/README.md](efi/README.md)。
- **法律**：以下不是法律意见。NVIDIA 驱动和固件的许可条款、反规避法规（例如美国 17 U.S.C. §1201）、出口管制规则可能适用于你所在的地区，请自行判断能否使用。
