# GeForce RTX 40 算力解锁（Windows）使用说明书

版本：安装器 0.3.0-experimental ｜ 状态：**实验性软件，本项目只实测过 RTX 4090（RTX 4080 16 GB 有用户报告验证）** ｜ 更新：2026-10-27

> 先读第 4 节"风险与须知"。这个工具会修改固件启动顺序，并在每次开机时对显卡写寄存器。使用风险自负。

---

## 1. 它是什么，能得到什么

**一句话**：把 GeForce RTX 40 系显卡上被限制为半速的"FP32 累加张量核心"解锁到满速（只实测过 RTX 4090，下面的效果数据都来自它）。解锁在每次开机时自动完成，你不需要按任何键。

**它不是**驱动、不是 VBIOS 刷机、不改熔丝，也不超频。它只是在 Windows 启动之前运行一个很小的程序，应用设置后再把控制权交给 Windows。设置在**断电或重启后会丢失**，所以每次开机都会重新应用。

**实测效果**（RTX 4090 24 GB，450 W 功耗上限，PyTorch 矩阵乘，单次测量；每项约 2 秒）：

| 测试 | 未解锁（TFLOPS） | 解锁后 | 变化 |
|---|---|---|---|
| TF32 4096³ | 83.7 | ≈130 | **+55%**（每 GHz 约 2×） |
| FP16（FP32 累加）4096³ | 159.3 | ≈214 | **+35%** |
| FP16（FP32 累加）8192³ | 152.9 | ≈168 | +10% |
| BF16（FP32 累加）8192³ | 156.5 | ≈178 | +14% |
| BF16（FP32 累加）4096³ | 144.0 | ≈145 | 基本无变化 |
| FP16（FP16 累加） | ≈237 / 225 | 同 | 不变 |
| FP32（CUDA 核心） | ≈52 | 同 | 不变 |

- 数值结果**逐位不变**（固定输入下，解锁前后输出的指纹相同）。
- 功耗一直顶在 450 W 上限，解锁后频率会下降，所以达不到理论上的 2 倍。
- **受益**：用混合精度的训练/微调、扩散模型（ComfyUI 等）、FlashAttention、大模型提示词预填充（以上我只测了矩阵乘基准，没有测这些真实应用）。
- **不受益**：游戏、DLSS、光追、大模型逐词生成（带宽受限）、INT8、FP32 标量计算。FP8 没测。

## 2. 工作原理（简版）

1. 安装时，在内部硬盘划一个 300 MiB 的隐藏 FAT32 小分区（或用你指定的 FAT32 U 盘），放入一个 UEFI 小程序和约 85 MB 的 NVIDIA 固件文件，并在固件启动顺序里加一项 **"GPU Unlock (auto)"**，排在 Windows 前面。
2. 每次开机，固件先运行这个小程序：它做一系列检查，确认是预期的那张卡、处于冷态；通过后释放固件的显卡驱动、让显卡内的签名固件执行一次写入、复位显卡，再把显示交还给固件，最后启动 Windows。屏幕会短暂变黑。
3. **第一次开机**时，程序会先**只读**地记下这张卡的身份信息（保存为 `PROFILE.TXT`），然后在同一次开机里继续解锁。以后开机直接读这个文件。
4. 检查在释放显卡的显示驱动**之前**没通过，程序就放弃，Windows 照常启动，只是这次不解锁；在那**之后**没通过，程序会停住并要求你断电（开机会卡在黑屏，见第 4 节）。

**为什么开关要重启才生效**：解锁必须在 Windows 的 NVIDIA 驱动加载**之前**完成，驱动加载后无法再做。所以窗口里的开/关改的是"下次开机做不做"，当前这次开机的状态不变。

## 3. 适用范围与前提

**必须满足**（安装器的"检查系统"会逐项检查）：

| 项 | 要求 |
|---|---|
| 显卡 | **恰好一张**受支持的显卡：RTX 4090（已验证）、RTX 4080（已有用户报告验证，见下）；或 4080 SUPER、4070 Ti SUPER（AD103 版 `10DE:2705` 和 AD102 版 `10DE:2689` 都可以）、4070 Ti、4070 SUPER、4070（**实验性**，见下）。显存为标准容量 |
| 系统 | Windows 10 / 11，64 位 |
| 启动方式 | UEFI（不是传统 BIOS/CSM） |
| Secure Boot | **必须关闭**（程序没有签名） |
| BitLocker | **必须关闭**（改启动路径会触发恢复） |
| 显示器 | 只接在这张显卡上（建议只接一根线） |
| 权限 | 管理员 |
| 空间 | 一个可缩小 304 MiB 的 NTFS 卷（GPT 磁盘），或一个有 150 MB 空闲的 FAT32 U 盘；下载约需 400 MB（检查要求缓存所在的盘至少有 1 GB 空闲） |

**不支持**：48 GB 魔改卡、4090 D、笔记本显卡、RTX 4060 系列、30 系和 50 系、多显卡、Secure Boot 开启的系统；有核显的配置可能被程序拒绝（它要求固件里恰好只有这张显卡的一个显示输出）。

**4090 以外的显卡**：本项目没有这些卡，**自己从没在它们上测试过**，支持依据别人的报告（见 README）；其中 RTX 4080 16 GB 已有一份用户报告确认可用（https://github.com/Zihao-Wu06/gpu-unlock-for-windows/issues/8），但仍和其他卡一样走分步流程：
1. 安装时窗口会多一个确认项；安装后第一次开机**只读取**显卡信息，不向显卡写任何内容；
2. 你点 **"试解锁一次"**，再重启，下一次开机才尝试解锁一次（许可在尝试之前就用掉，黑屏也不会重复）；
3. 试解锁成功（大卡片显示"本次开机试解锁成功"）、你用一段时间确认正常之后，才会出现 **"开启自动解锁"**。在那之前，开关只是让开机程序保持开启（读取显卡并等待），你随时可以关掉，同时会取消还没执行的试解锁。

## 4. 风险与须知（请认真读）

- **实验性**：只在一台测试机（华硕 ROG STRIX Z790-H + i7-14700KF + 24 GB 华硕 4090，BIOS 3107，驱动 610.88）上验证过。解锁事务成功了十余次，没有出现过事务中途失败；另有 3 次被程序自己的预检在写入显卡之前拦下（原因已修复）。样本很小。
- **它改了什么**：固件启动顺序；分区模式下会把一个卷缩小 304 MiB 并新建小分区。卸载时会还原。
- **每次开机都会对显卡写寄存器**，成败没人盯着。事务中途失败时程序会**停住并要求你断电**，开机会卡在黑屏。
- **没有开机取消窗口**（已去掉倒计时）。想让某一次开机不解锁：开机时反复按主板的**启动菜单键**（华硕一般是 F8，其他品牌常见 F11/F12），在启动菜单里直接选 **Windows Boot Manager**。想长期不解锁：在窗口里把开关关掉。
- **快速启动（Fast Startup）**：开启时，"关机"会恢复上次保存的 Windows 会话而不是全新启动，本工具没有在这种情况下测试过，它也可能和开机程序修改的文件冲突。"检查系统"会在它开启时给出警告；请关闭它，或者一律用"重启"。
- **睡眠（S3）恢复后解锁会丢**（预期如此，我没有专门测过）：重启一次即可恢复。休眠/快速启动在测试机上没有启用，开启时的行为未验证。
- **BIOS 更新、增删 PCIe/硬盘、改显卡相关 BIOS 设置**可能让已保存的显卡信息对不上，程序会拒绝解锁（Windows 照常启动）。这时在窗口里点"重新登记显卡"。
- **Windows 更新**有可能改写启动顺序（我没遇到过，也没法保证）；如果发现性能回到了未解锁水平，先看窗口里的状态。
- **合规**：我不是律师。显卡的 EULA 对逆向和修改的限制、反规避法规、出口管制规则可能适用，上游项目的文档也都这样提醒。请自行判断是否适合你。NVIDIA 的固件文件**不随本工具分发**，安装时由你的电脑从官方下载并校验后在本机提取。本工具与 NVIDIA 无任何关联。

## 5. 安装

**准备**
1. 在 BIOS 里把 **Secure Boot 关掉**；在 Windows 里关掉 **BitLocker**（"设备加密"也要关）。
2. 重要数据先备份。
3. 保存好手头工作，安装后需要重启。
4. 电脑要能联网（下载约 330 MB）。不能联网的话，见 8.4 手动放缓存。

**步骤**
1. 下载并解压发布包（或克隆仓库），打开 `installer` 文件夹，双击 **`GPU-Unlock-Installer.cmd`**，在系统提示里选"是"（管理员）。
2. 点 **"检查系统"**，下方"系统检查"页确认没有红色"未通过"。黄色"注意"是提醒，"未通过"必须先解决。
   - 窗口右上角可切换 **中文 / English**，整个界面（包括检查结果和运行记录）都会换成所选语言，选择会被记住。
3. 点 **"安装…"**：
   - **内部硬盘小分区（推荐）**：从下拉框里选一个卷（默认选最合适的），会缩小它 304 MiB 并新建 300 MiB 的 FAT32 分区；
   - **FAT32 U 盘**：选一个 U 盘盘符，不会格式化，U 盘必须一直插着；拔掉后电脑直接正常启动。
4. 勾选"我了解这是实验性软件"，决定是否"安装后立即开启"（默认开启），点"开始安装"。
5. 等待：下载并校验、提取固件、分区、拷贝并校验、建启动项。约几分钟（取决于网速）。
6. 弹出"现在重启吗"时选"是"。**第一次开机**会先读取显卡信息，然后在同一次开机里解锁。

**命令行方式**（可选，在管理员 PowerShell 里）：
```
powershell -ExecutionPolicy Bypass -File core.ps1 install -Mode partition -TargetVolume H
powershell -ExecutionPolicy Bypass -File core.ps1 install -Mode usb -Drive E:
```
加 `-DryRun` 只打印计划不做任何改动。加 `-Lang zh` 或 `-Lang en` 指定输出语言（不加时沿用窗口里选的语言，否则跟随 Windows 显示语言）。

## 6. 日常使用

打开窗口后，最上面的大卡片显示**当前这次开机是否已解锁**（绿点 = 已解锁，灰点 = 未解锁，红点 = 本次解锁失败，黄点 = 已安装、等重启），右侧是**开机自动解锁**开关。下面四个小卡片是：安装状态、开机程序文件、显卡信息、显卡型号。

| 想做什么 | 怎么做 |
|---|---|
| 开启自动解锁 | 把右上方的 **"开机自动解锁"** 开关拨到开（变绿），选"现在重启"。重启后生效 |
| 关闭自动解锁 | 把开关拨到关（变灰），选"现在重启"。重启后不再解锁，也没有任何等待 |
| 看现在是否已解锁 | 看大卡片：显示 **"本次开机已解锁"**（绿点）才表示这次开机已解锁；"当前未解锁"表示这次开机没有运行解锁（解锁每次重启都会清除） |
| 这一次不解锁 | 开机按主板的启动菜单键（华硕一般是 F8，其他常见 F11/F12），选 **Windows Boot Manager** |
| 查看详细日志 | 点 **"开机日志"**（开机程序的原始技术日志，只有英文） |
| 换了显卡/升级了 BIOS | 点 **"重新登记显卡"**，重启（会同时重置实验性显卡的试解锁状态） |
| 实验性显卡：试解锁 | 点 **"试解锁一次"**，选"现在重启"。下一次开机尝试解锁一次；成功后，同一个按钮变成 **"开启自动解锁"**，点它并重启 |
| 切换界面语言 | 点右上角 **中文 / English** |
| 彻底删除 | 点 **"卸载"** |

**自己验证是否解锁**（需要装有 CUDA 版 PyTorch）：对同一张卡，TF32 8192³ 的矩阵乘在 450 W 的 4090 上，未解锁约 84 TFLOPS，解锁后约 127 TFLOPS。仓库 `tools/` 目录里的 `bench_gemm.py` 会一次测多项并输出 JSON（用法：`python bench_gemm.py 名字`）。注意 cuBLAS 对不同尺寸/精度会选不同内核，某些组合（如 BF16 4096³）看不出变化，这不代表没解锁；TF32 最明显。

## 7. 卸载

1. 打开窗口，点 **"卸载"** 并确认。
2. 会删除启动项；**分区模式**会删除那个小分区，并把空间还给原来的卷（已实测：被缩小的卷恢复到原来的精确大小）；**U 盘模式**只删除我们放的两个文件夹。
3. 卸载后重启，显卡回到默认（半速）状态。
4. 可选：删除 `C:\ProgramData\GPU-Unlock`（下载缓存约 340 MB、提取用的临时 Python、日志）。

## 8. 常见问题与排障

**8.1 "检查系统"有"未通过"**
| 提示 | 处理 |
|---|---|
| Secure Boot 开启 | 进 BIOS 关闭 Secure Boot |
| BitLocker 开启 | 关闭 BitLocker / 设备加密 |
| 找不到支持的显卡 / 显存容量不符 | 本工具只支持 README 里列出的 RTX 40 系型号，且要标准显存容量；改版显存的卡不支持 |
| 没有可缩小的卷 | 改用 U 盘模式，或用磁盘管理释放空间 |
| 下载主机解析失败（⚠） | 检查网络，或按 8.4 手动放缓存 |

**8.2 开机卡在黑屏 / 出现 STOP**
长按电源键约 5 秒断电，再开机时反复按启动菜单键（华硕一般是 F8，其他常见 F11/F12），选 **Windows Boot Manager**。进系统后在窗口里把开关关掉，然后在 GitHub 上提 issue，附上"开机日志"的内容（`FINAL` 行最重要）以及主板、BIOS 版本和显卡型号。

**8.3 状态显示"未解锁"**
- 先看大卡片：如果显示"最近一次运行……属于更早的开机"，说明这次开机程序没有运行（开关是关的，或启动项被移走）。
- 点"开机日志"，找 `FINAL` 行：`stage=…` 告诉你停在哪一步；`status=0x8…` 表示被预检拦下，没有写入显卡。常见原因：显示器没接在 4090 上、固件暴露了不止一个显示输出（接多台显示器时可能出现）、BIOS 设置改动。
- 重新登记后再试。

**8.4 不能联网 / 下载很慢**
在能上网的电脑上下载这三个文件，放进 `C:\ProgramData\GPU-Unlock\cache\`，安装器会逐个核对 SHA-256。（archive.cachyos.org 只接受 TLS 1.3：Windows 11 支持，Windows 10 可能连不上，这时用别的电脑或浏览器下载那个文件即可。）
- `NVIDIA-kernel-module-source-610.43.03.tar.xz`（26,172,192 字节），来自 download.nvidia.com；
- `nvidia-utils-610.43.03-1-x86_64_v3.pkg.tar.zst`（314,789,539 字节），来自 archive.cachyos.org；
- `python-3.14.0-embed-amd64.zip`（11,994,671 字节），来自 python.org（只用来本地提取固件）。

**8.5 BIOS 更新 / 换硬件后不解锁**
点"重新登记显卡"并重启。程序会重新读取显卡信息。

**8.6 手动停用（窗口打不开时）**，在管理员命令提示符里：
```
bcdedit /enum all
```
找到描述为 "GPU Unlock (auto)" 的项的标识符 `{...}`，然后：
```
bcdedit /set {fwbootmgr} displayorder {该标识符} /remove
```
这只是把它从启动顺序里拿掉（相当于"关闭"）。彻底删除再加：`bcdedit /delete {该标识符}`。

## 10. 已验证与未验证

**已验证（一块 RTX 4090）**：实验性显卡的分步流程（在 4090 上用 `trial_required=1` 强制走了一遍：只读等待、试解锁一次、确认自动、重新登记，命令行方式）、新版开机程序读取旧版显卡信息、窗口里的开关（开/关）、卸载与重新安装（用户实际点击）、高分屏缩放下的界面（模拟 125%/150%）、检查、下载校验与固件提取（5/5 哈希一致）、工具安装与卸载（被缩小的卷恢复到精确原大小）、首次开机登记并同次解锁、重启后按开关自动解锁、预检被拦下时不写入显卡且 Windows 照常启动、去掉倒计时后的开机解锁、数值输出不变、ReBAR（BAR1 32 GiB）保持。

**未验证**：
- 在窗口里实际点"试解锁一次"等实验性流程的按钮（界面只做了渲染检查，流程是用命令行测的）；
- **任何非 4090 的显卡**（芯片表、显存范围、芯片编号检查都是按上游文档写的，从没在那些卡上运行过；只有 RTX 4080 16 GB 有一份用户报告确认可用）；
- 安装窗口里的 U 盘选项；
- 联网下载（测试机当时没有外网：下载走的是预先放好的缓存，下载代码只在本机的 TLS 1.3 测试服务器上跑过，没有连过真实网站；CachyOS 的服务器需要 TLS 1.3，Windows 10 可能不支持，失败时按 8.4 手动放缓存）；
- U 盘模式；安装中途失败的自动回滚；
- 睡眠恢复后的行为；Windows 大版本更新、BIOS 更新之后的行为；
- 真实应用（训练、ComfyUI、LLM）的收益；长时间满载稳定性；
- 任何其它电脑和其他显卡型号。
